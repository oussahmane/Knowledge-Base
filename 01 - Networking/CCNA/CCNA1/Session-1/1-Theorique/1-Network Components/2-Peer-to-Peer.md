
- It is possible to have a device be a client and a server in a Peeer-to-Peer Network. This type of network design is only recommended for very small networks.

| Advantages                                                     | Desadvantages                 |
| -------------------------------------------------------------- | ----------------------------- |
| Easy to set up                                                 | No centralized administration |
| Less complex                                                   | Not as secure                 |
| Lower cost                                                     | Not scalable                  |
| Used for simple tasks: transferring files and sharing printers | Slower performance            |
